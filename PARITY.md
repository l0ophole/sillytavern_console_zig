## Stage 0 — reliability regressions (all tested; upstream ref 06bde939fb1e9c4c8d8641d810f0a916b5bce127)

Strict smoke harness: every `tests/run.sh` assertion failure increments `FAILURES` and exits nonzero (including `&&` chains converted to `|| fail`); `ALL SMOKE TESTS PASSED` prints only with zero failures; skips are counted/listed separately (`SKIP_NO_NODE`, `SKIP_NO_OPENROUTER_KEY`, `SKIP_WEBUI_PATH`, …) and never counted as PASS. Proven by `ST_FORCE_FAIL=1 sh tests/run.sh` → exit 1, `FAILURES=1`, no `ALL SMOKE TESTS PASSED`. No hard-coded paths (`mktemp -d`, `$ZIG`/`PATH`/`~/.local/zig`, `ST_UPSTREAM` default `../SillyTavern`, HF cache via `$HF_HOME`/`$XDG_CACHE_HOME`); dependencies `python3 grep curl` + stdlib import checked up front (fatal exit 1 if missing).

- [x] implemented+tested: `extensions.execute*` unconditionally returns `execute_disabled`; `ST_ALLOW_EXECUTE` parsing removed (dead opt-in deleted). Caller code is never executed by the server.
- [x] implemented+tested: auth token required on every user-data endpoint (TCP `params.token`, HTTP `X-ST-Token`). Exemptions: TCP `ping`/`version`/`health`, HTTP `/api/health`+`/api/ping`, and TCP `users.validate`/`users.logout` (carry their own session token; server-token check would block them). Verified: unauth HTTP → 401, wrong token → 401, unauth TCP `settings.get`/`chats.list` → `unauthorized`; `frontend.http_verify` now sends `X-ST-Token` and checks ` 200 `.
- [x] implemented+tested: `--port 99999` (and other bad ports) exits 1 with clean `invalid port (must be 0-65535)` on both `st-client` and `st-server` — no Zig stack trace, no crash.
- [x] implemented+tested: REPL double-free fixed at cause — `pending.items = pending.items[nl+1..]` resliced the ArrayList allocation, corrupting capacity accounting; replaced with `consumed` offset + periodic compaction (`PASS_REPL_STRESS`: 2,000 `/ping` lines → 2,000 pongs, exit 0; also 5,000-line manual check). - [x] implemented+tested: replies >64 KiB and buffered save/load >1 MiB — `MAX_LINE` 16 MiB; `PASS_BIGCHAT_SAVE`/`PASS_BIGCHAT_LOAD` (1,200 msgs, ~1.2 MiB, <1 s) and `PASS_BIGFILE` (200,000 chars) complete with no truncation. Backend errors/interrupted streams: `PASS_INTERRUPTED_STREAM` (partial `"Partial"` saved) + `PASS_ALIVE_AFTER_CUT`; card→prompt→streamed OpenAI reply→save/reload preserved.
- [x] implemented+tested: input validation via `std.math.cast` for all user integer fields (ports, dim, limit, max_tokens) → `bad_request`, never panic. Verified `port:99999` → `bad_request`, server stays alive.
- [x] implemented+tested: growable buffers everywhere (server `readAllAlloc`, client read-until-EOF/newline, HTTP bridge read-until-EOF). Verified 100 KB character round-trips via TCP client and HTTP (valid JSON, 100000 chars).

Deliberate differences (Stage 0): token is a local-machine secret, not SillyTavern's multi-user account session (upstream `enable_accounts` is off by default); HTTP body format for errors is `{"error":...}` with 400, matching JS `sendStatus` class.
